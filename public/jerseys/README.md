# Trikot-Bilder

Hier liegt pro Club ein Trikot-Bild, benannt nach dem Club-Kürzel aus der
Datenbank (`clubs.short_name`):

```
YB.png   Young Boys           LUZ.png  Luzern
BAS.png  Basel                LS.png   Lausanne
ZUR.png  Zürich               THU.png  Thun
SG.png   St. Gallen           SIO.png  Sion
GC.png   Grasshoppers         VAD.png  Vaduz
SFC.png  Servette             LUG.png  Lugano
```

## Eigenes Design einsetzen

Einfach die jeweilige Datei **ersetzen** — gleicher Name, Format PNG:

- Quadratisch, empfohlen **256×256 px** (mind. 128×128)
- **Transparenter Hintergrund**
- Das Trikot sollte die Fläche möglichst ausfüllen (wenig Rand)

Die App lädt automatisch das neue Bild; ggf. Browser-Cache leeren (Cmd+Shift+R).
Fehlt eine Datei, zeigt die App ein neutrales graues Trikot als Fallback.

Die aktuellen Platzhalter wurden generiert — Vorlage/Skript siehe Git-History
oder einfach mit eigenen Designs überschreiben.
